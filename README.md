# 麻辣湯（マーラータン）の例のあれ

マーラータンに入っている、オレンジと白の縞のあの団子。
押している間だけオレンジを塗って、あの縞の団子を自分で作るワンタッチゲームです。

スマホ縦画面。ブラウザでそのまま遊べます。1回5秒ほど。

**遊ぶ：https://kome0824.github.io/mala-reinoare/**

## 遊び方

1. 縞の本数を選びます：4本（まかない）／8本（屋台）／12本（名人・回る速さがゆらぐ）
2. 押すと団子が回り出します。ちょうど1周だけ回ります。
3. 押している間だけオレンジを塗ります。離すと白。
4. オレンジの縞を選んだ本数だけ、白とかわりばんこに同じ幅で塗ります。
5. 1周すると横から見た団子ができあがり、点数と称号、マーラータンの小ネタが出ます。
6. 「Xに投稿」で、結果の画像と文を投稿できます。

## 点数と称号

縞の幅のそろい具合と、オレンジの本数で決まります（100点満点）。

- 95点以上「伝説の団子職人」
- 85点以上「屋台の看板」
- 70点以上「一人前」
- 50点以上「見習い」
- 30点以上「まかない係」
- それ未満「具が迷子」

自己ベストは、本数ごとにこのブラウザに保存されます。
